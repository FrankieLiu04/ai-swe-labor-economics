# Data

No raw proprietary or copyrighted datasets are committed yet.

## Candidate datasets

- job-posting data with seniority, occupation, location, firm, and date;
- payroll/employment microdata where accessible;
- compensation data for junior and senior SWE by region;
- model API pricing history;
- coding-agent benchmark trajectories;
- developer telemetry measuring review time and accepted output;
- firm-level AI adoption / approved-tool rollout dates.

## Data principles

1. Preserve provenance and licensing information.
2. Separate public raw data, derived data, and manually coded variables.
3. Store reproducible transformations in code when data collection begins.
4. Do not scrape or redistribute data in violation of terms of service.
